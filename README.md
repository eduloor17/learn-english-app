# 📚 Curso Básico de Inglés: Lecciones de Supervivencia

Este es un repositorio de lecciones interactivas diseñado para principiantes absolutos (**Nivel A1-A2**) que buscan construir una base sólida en el idioma inglés. El proyecto está construido con HTML, CSS (un archivo simple `styles.css`) y JavaScript puro para la interactividad (principalmente usando la API de Síntesis de Voz del navegador).

## 🚀 Cómo Empezar

1.  **Clona o Descarga** este repositorio a tu computadora.
2.  Abre el archivo `index.html` en tu navegador web (Chrome, Firefox, Edge, etc.).
3.  ¡Empieza la primera lección!

> **Nota:** Este proyecto no requiere conexión a Internet ni un servidor web para funcionar.

## 📖 Estructura del Curso (Nivel Básico)

El curso está organizado en un directorio `/lessons/basic/` con archivos HTML individuales, y las hojas de estilo se encuentran en `/styles/styles.css`.

| Lección | Archivo | Contenido Principal |
| :--- | :--- | :--- |
| **Lección 1** | `lesson-alphabet.html` | El Alfabeto (sonidos de letras) y Números 1-20. |
| **Lección 2** | `lesson-greetings.html` | Saludos formales e informales, y despedidas. |
| **Lección 3** | `lesson-colors.html` | Colores básicos y uso de los artículos **A / AN**. |
| **Lección 4** | `lesson-tobe.html` | El Verbo **To Be** (Ser o Estar) y conjugación con 14 ejemplos prácticos. |
| **Lección 5** | `lesson-family.html` | Vocabulario de la familia y uso de pronombres posesivos (**His, Her, Their**). |

## ✨ Características Clave

* **Audio Integrado:** Usa la **Web Speech API** del navegador para pronunciar las palabras y frases. (Recomendado usar navegadores modernos).
* **Diseño Simple:** Enfocado en la claridad y facilidad de uso para el estudiante.
* **Ejercicios Interactivos:** Práctica de escritura y diálogo en cada lección.

## ⚙️ Tecnologías Utilizadas

* **HTML5:** Estructura del contenido.
* **CSS3:** Estilos (Archivo `styles.css`).
* **JavaScript:** Interactividad y función de voz (`speakText`).
